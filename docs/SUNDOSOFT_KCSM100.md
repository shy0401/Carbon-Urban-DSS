# 선도소프트 탄소공간지도 100m 건물 전기 배출 (2026-10-17 적용)

선도소프트(이용채 주임)가 보낸 **전주 지역 전력 배출량 고해상도 지도**를 이 도구에 붙인 기록입니다. 요청한 곳은 행정동 송천1동·효자5동이었지만 탄소공간지도는 법정동 기준으로 만들어져 전주 전체(덕진구·완산구)를 받았습니다. 이 도구는 100m 칸을 행정동 경계로 직접 잘라 더하므로 행정동 값을 따로 받을 필요가 없습니다.

- 원본과 값은 Git에 올리지 않습니다(`data/raw/sundosoft_kcsm100/`, `.gitignore`의 `data/`). 이용 조건(외부 공개·재배포)을 받기 전이라 **공개 시연 주소에서는 지도 레이어·지역 시뮬레이션 표·보고서 문장을 모두 뺍니다.**
- 이 문서에는 칸별 값을 적지 않고 구조·개수·비율만 적습니다.

## 1. 받은 것

| 항목 | 내용 |
|---|---|
| 묶음 | `1. 배출_건물_전기_격자_100m/` 아래 `공간정보(shp)/` SHP 4벌, `속성정보(csv)/` CSV 4개, `탄소배출_건물_전기_격자_데이터정의서.xlsx` |
| 범위 | 전북특별자치도 전주시 덕진구·완산구 × 2023·2024년 (메일: 2024년까지만 제공 가능) |
| 행 | (100m 칸, 법정동) 한 쌍. 법정동 경계에 걸친 칸은 법정동마다 한 행. 덕진구 13,287행·완산구 10,905행(해마다 같음) → 칸 21,036개 |
| 격자 | `grid_cd` = 국가기본격자 100m 코드(`다마555632`). SHP 도형(EPSG:3857)을 EPSG:5179로 바꾸면 코드의 칸(x = 900,000 + 555×100, y = 1,700,000 + 632×100)과 꼭짓점이 0m 차이로 같음 |
| 값 | `e1`~`e12` 월, `e_sum` 연, 단위 tonCO2-eq(정의서). 빈 값 없음, 음수 없음, 월 합과 연 합 일치(차이 0.02 t 넘는 행 0) |
| 부문 | 건물 **전기만**. 가스·지역난방·수송 없음 |

### 정의서와 다른 점 (확인 필요로 기록)

- 정의서의 열 이름은 `e_01`~`e_12`, `e_tot`인데 파일은 `e1`~`e12`, `e_sum`입니다. 가져오기는 둘 다 읽습니다.
- 파일에는 정의서에 없는 `emd_cd`(법정동 8자리)가 있습니다.
- 정의서의 좌표계는 EPSG:3857로 SHP와 같습니다. CSV에는 좌표가 없고 칸 코드로 위치를 정합니다.
- 산정에 쓴 배출계수, 0의 뜻, 이용 조건은 받은 자료에 없습니다.

## 2. 넣는 방법

```powershell

#    data/raw/sundosoft_kcsm100/2026-10-17/1. 배출_건물_전기_격자_100m/...

```

- 한 연도의 두 구 파일을 함께 읽어 칸마다 한 행(`kcsm_grid100`, 열 `annual_t`·`monthly`·`parts`·`flags`)으로 저장합니다. 같은 파일을 다시 넣으면 SHA-256을 비교해 건너뜁니다(`kcsm_imports`).
- 넣은 뒤 연도끼리 급감 표시(`flags.drop`)를 다시 계산합니다. 값은 고치지 않습니다.

## 3. 값 처리 ([기준](DATA_STANDARD.md) 4·5.12절)

| 상황 | 처리 |
|---|---|
| 0 (행의 약 70%) | 제공값 0 그대로. 화면에 "0 (제공값, 확인 필요)". 건물이 없는 칸인지 사용량이 연계되지 않은 칸인지 모름 |
| 앞 해 ≥ 100 tCO2eq → 다음 해 절반 미만 | "급감(원자료 누락 의심)" 표시. 합계에는 제공값 그대로 넣고 칸 수와 앞 해·이번 해 합을 함께 적음 |
| 이 도구 값(건축HUB × 승인 계수)과의 관계 | 더하지 않음. 같은 500m 격자 범위끼리 비율로만 맞댐 |

## 4. 화면에서

- **지도 분석 → 레이어 → "100m 전기 배출 (탄소공간지도)"**: 확대 13 이상에서 화면 안 100m 칸을 연간 tCO2eq 고정 구간(10·50·150·400·1,000)으로 칠합니다. 0은 옅은 회색, 급감은 빗금, 칸을 누르면 그해 값과 앞 해 대비 변화가 뜹니다. 2025년 지도에서는 2024년 값을 쓰고 그렇게 적습니다.
- **격자 상세 "100m 전기 배출 25칸"**: 고른 500m 칸 안 25칸(5×5, 북쪽 위)과 25칸 합·앞 해 합.
- **지역 시뮬레이션 → "건물 전기 배출 (탄소공간지도 100m · 선도소프트 제공)" 표**: 연도마다 ① 경계(행정동·다각형·반경) 안 100m 칸 합, ② 구역 500m 격자 범위 합, ③ 같은 격자의 건축HUB 계측 전력 × 그해 승인 계수와 그 비율, 급감 칸 수.
- **감축 노력의 기준 건물 "건물 전체 (탄소공간지도 100m)"**: 기준 = ①(가장 최근 자료 연도, 지금 2024), 신축 부하 원단위 = ② ÷ 같은 격자의 건축물대장 연면적(그해까지 사용승인)이며 kgCO2eq/m²·년. 필요 감축량·효율 개선률은 탄소 값만으로 계산하고, 재생에너지 kWh·태양광 kW는 이 도구의 전력 계수로 나눈 환산값입니다. 다른 기준(공동주택·건축HUB)은 2025년까지 관측으로 계산하므로 **기준 연도가 다릅니다**.
- 보고서에는 "2-1. 탄소공간지도 100m 전력 배출" 절과 표가 들어갑니다(이 PC에서 만든 보고서만).

## 5. 선도소프트에 물어볼 것

1. 산정에 쓴 전력 배출계수(연도별)와 GWP — 이 도구의 kWh 환산·건축HUB 대조에 필요
