# 지역 개발 시뮬레이션 (/area)

2026-09-25 추가. 웹 메뉴 **지역 시뮬레이션**.

## 할 수 있는 일

1. 구역을 고릅니다.
   - 행정동 35개 (목록에서 고르거나 지도에서 동을 누름)
   - 반경 100~5,000m (지도를 누른 곳이 중심)
   - 직접 그린 다각형
   - 용도지역 (주거·상업·공업·녹지·관리) 격자 묶음
   - 예비 선정 격자
2. 과거와 현재를 연도별로 봅니다 (기본 2015~2025). 슬라이더와 재생 버튼으로 연도를 바꾸면 지도의 단지가 준공 전 빈 원에서 준공 뒤 채운 원으로 바뀝니다.
   - 기존 단지: 회색
   - 개발 연도 단지: 호박색
   - 이후 단지: 보라
   - 그 해 준공: 검은 테
3. 개발 전후 영향을 봅니다. 개발 연도(자동 또는 선택)의 앞뒤 1~5년 평균을 비교하고, 개발 연도 자체는 전환기라 뺍니다.
   - 관측: 12개월 완전 지번만 씁니다. 지역 합계 변화, 기존 단지만의 변화, 신규 단지 비중을 봅니다.
   - 추정: 준공 단지 연면적 × 전주 관측 원단위로 냅니다. "이 개발만의 증가"는 직전 연도 재고 대비로 계산해서 다른 해의 개발과 섞이지 않습니다.
   - 맥락: 난방도일·냉방도일·인구의 전후 평균입니다.
4. 미래 개발의 감축 노력을 봅니다. 계획 조건과 목표 감축률(0~100%, 화면 입력)을 넣습니다. 계획 조건은 추가 연면적 또는 층수×동수×건축면적, 그리고 철거 연면적입니다.
   - 기준, 개발 후(추가 대책 없음), 목표 탄소를 비교합니다.
   - 필요 감축량을 보여 줍니다.
   - 신축만 개선할 때의 필요율을 보여 줍니다. 100%를 넘으면 불가로 표시하고, 신축 원단위 목표도 함께 보여 줍니다.
   - 지역 전체 효율 개선률과 재생에너지 상쇄 kWh를 보여 줍니다.
   - 태양광 kW는 사용자가 발전량 가정을 넣을 때만 계산합니다.
   - 목표별 곡선을 그립니다.
5. 보고서를 만듭니다. 근거 문장으로 요약을 씁니다. 로컬 AI를 켜면 모델 문장을 검증해서 숫자·연도·증감 방향이 하나라도 다르면 게시하지 않고 서식으로 바꿉니다. 결과는 저장되고 마크다운으로 내려받을 수 있습니다. 목록은 기존 검토 보고서와 분리됩니다.

## 데이터 규칙

- 관측이 없는 연도는 0이 아니라 "자료 없음"(해치)으로 둡니다. 추정선은 따로 그리고 "추정" 배지를 붙입니다.
- 행정동 통계(인구)는 격자·반경에 배분하지 않습니다. 겹치는 행정동 값은 참고로만 씁니다.
- 탄소 계수는 최신 등록 전력 계수를 모든 연도에 똑같이 적용하고, 화면과 보고서에 이 사실을 적습니다. 가스는 계수를 확정한 뒤 넣습니다.
- 개발 이력은 K-apt 사용승인일에서 가져옵니다. 연면적 이상치는 제외합니다.
- 기준 부하는 지역 관측이 있으면 관측값(OBSERVED)을 쓰고, 없으면 연면적 × 전주 원단위 추정(ESTIMATED)을 씁니다. 화면에 어느 쪽인지 배지로 표시합니다.

## 과거 자료 채우기 (PC에서 한 번)

```powershell
scripts\dss.cmd CollectHistory -FromYear 2015 -ToYear 2025
```

- 먼저 백업을 만든 뒤 SGIS, ASOS(실패 시 ERA5-Land), K-apt 월별 에너지, 건축HUB 지번 에너지를 연도순으로 받습니다. VWorld 건물·지적은 마지막에 한 번 받습니다.
- K-apt는 단지별로 사용승인 이전 달을 건너뛰어 호출 수를 줄입니다.
- 인증 오류나 일일 한도에 걸리면 그 데이터셋만 멈추고 기록합니다. 같은 명령을 다시 실행하면 끝난 항목은 건너뛰고 이어서 받습니다.
- 진행 기록은 `data/ops/history-progress.json`에 남고, 화면 상단에도 표시됩니다 (`GET /api/areas/collection`).

## API

| 메서드 | 경로 | 내용 |
|---|---|---|
| GET | `/api/areas/options` | 행정동 목록과 경계, 용도지역별 격자 수, 관측 연도, 기준 격자 |
| POST | `/api/areas/analyze` | `{area, from_year, to_year, event_year?, window, plan?, target_pct?, pv_yield_kwh_per_kw?}` → history, before_after, effort, grid_features, facts |
| GET | `/api/areas/collection` | 과거 수집 진행 |
| POST / GET | `/api/area-reports`, `/{id}`, `/{id}/markdown` | 지역 보고서 |
