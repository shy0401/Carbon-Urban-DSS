# 시나리오와 최적화

그리드250,000m²와 개발가능 부지면적을 구분한다. `footprint = 동수 × 동당 건축면적`, `gross_floor_area = footprint × 층수`, `FAR = 산정 연면적 / 개발가능 부지 ×100`, `BCR = footprint / 개발가능 부지 ×100`이다. 초기 계획안은 지상 연면적 전체를 FAR 산정면적으로 가정한다. 법정 제외면적을 자동 추정하지 않는다.

월별 시나리오 소비는 `관측 월별 kWh / 매칭 기준 연면적 × 계획 연면적 × 효율 배율`이다. 전기에는 `1−PV비율`을 곱한다. PV는 수요 상쇄율 입력이며 설비면적·일사량 기반 발전량 모델이 아니다. 녹지비율은 공간 수용조건에만 사용하고 근거 없는 에너지 절감계수는 적용하지 않는다.

현재값·계획값·차이·변화율을 분리한다. 기준값이0 또는 결측이면 변화율을 계산하지 않는다. 현재와 면적이 동일하고 효율1·PV0이면 월별 에너지와 일치한다. 기준 월별 패턴에 포함된 날씨의 계절성을 유지하며 독립적인 기상 인과효과로 설명하지 않는다.

결정론적 최적화는 동수1~부지수용한도(최대80),층수3~40을 열거한다. 세대수는 연면적/가정한 세대당 공용 포함 면적, 인구수용량은 입력 세대당 인원으로 계산한 **계획치**다. 최소세대·최소인구·녹지와 건축면적 제약을 검사한다.

전체 운영탄소가 계산 가능하면 탄소를 최소화한다. 그렇지 않으면 확보된 에너지원의12개월 관측만으로 목적함수를 명확히 제한한다. 최소한 한 에너지원의12개월 관측과 매칭된 연면적이 없으면 대안을 순위화하지 않는다.

대안은 총량 최소,세대당 최소,최솟값의20% 이내에서 수용량 최대다. 선형 모델의 세대당 목적값은 동률일 수 있으며 총량·동수·층수로 재현 가능한 순서를 정한다. 법적 규제 미확정 결과는 `ENERGY_OPTIMAL`이지 `LEGAL_OPTIMAL`이 아니다.
