# 팀 데이터셋 연동 (urban-carbon, 윤영준, 2026-10-01)

팀원이 네 도시(전주시·세종시·부산 강서구·서울 강동구)의 2016·2019·2022·2024년을 500m·100m 국가기본격자(EPSG:5179)로 정리한 데이터셋을 이 도구에 붙였습니다. 격자 ID(`다마71b61b`)와 좌표가 이 도구의 500m 격자(`cell_<x>_<y>`)와 같아 칸끼리 바로 잇습니다.

## 1. 넣은 것과 넣지 않은 것

| 팀 자료 | 이 도구에 | 이유 |
|---|---|---|
| **탄소공간지도 500m 건물 배출** (전기·가스·지역난방, 월별·연간 tCO₂eq) | **넣음** → 지도 묶음 "건물 배출 (탄소공간지도)", 공식 통계 대조 | 이 도구에 없던 출처. 단독주택·지역난방까지 들어 있고 2016년부터 있음 |
| **국토통계지도 100m** 인구·건물 수·추정 연면적 | **넣음** → 100m 표 + 500m 합(지도 묶음 "국토통계지도 100m") | 없던 출처(100m 해상도). 국외 반출 금지 → 아래 3절 |
| 건축물대장 연면적의 격자 합 | 지도에는 **이 도구가 대장을 받지 않은 지역만** | 전주는 이 도구의 대장 수집과 겹침 |
| **개발 사례** (연면적이 크게 는 500m 칸 × 두 시점, 배출 전후) | **넣음** | 없던 자료 |
| SGIS 격자 통계(인구·가구·주택) | 넣지 않음 | 이 도구의 SGIS 500m(자료제공 신청분)와 같은 출처 |
| 기상(ASOS) | 넣지 않음 | 이 도구가 ASOS·ERA5-Land로 받음 |
| K-apt 단지·기본정보 | 넣지 않음 | 이 도구의 K-apt 목록·상세와 같음 |
| 건축HUB 지번 에너지(단지 80+143+30+25곳, 2021~2024) | 넣지 않음 | 이 도구는 같은 API를 법정동 단위 **전 지번**으로 받음. 대신 팀 자료에서 알게 된 규칙(전북은 2023-10 사용분까지 옛 시·군·구 코드 45xxx)을 수집기에 넣어 전주 2020~2023년도 전 지번으로 받게 함(`energy_parcels.request_sigungu`) |
| VWorld 지번·용도지역 원본 | 넣지 않음 | 이 도구가 지역을 준비할 때 받음 |
| 합본(`00_합본_1차`) | 읽지 않음 | 도시 표를 이어 붙인 것. 읽으면 같은 칸을 두 번 셈 |

## 2. 중복을 막는 규칙

- 한 칸은 **(데이터셋, 격자 ID, 연도)** 로 한 번만 저장합니다. 한 파일에 같은 칸이 두 번 있으면 하나만 남깁니다.
- 같은 파일을 다시 넣으면 SHA-256을 비교해 같으면 건너뛰고, 바뀌었으면 그 데이터셋·연도의 행을 지우고 다시 씁니다(누적되지 않음).
- 지도는 지역 코드가 같은 데이터셋만 씁니다(전주시 지도 ← `52110_전주시`). 구 경계 칸은 팀 데이터셋이 이미 두 구의 값을 더해 두었습니다.
- 지도 연도에는 그 이전의 가장 가까운 팀 연도를 씁니다(2025 → 2024, 2020 → 2019). 2016년보다 이른 해는 비웁니다.
- 빈 값은 결측입니다. 탄소공간지도에서 **건물이 있는데 0**인 칸(`zero_with_buildings`)은 원자료 누락으로 보고 비웁니다. 건물이 없어 0인 칸은 0으로 둡니다.

## 3. 이용 조건

- **국토통계지도(국토지리정보원): 국외 반출 금지.** 원본과 사본은 사용자 PC(`data/raw`, Git 제외)와 PC의 DB에만 둡니다. 공개 시연 주소(게이트웨이 경유) 응답에서는 국토통계 값과 그것을 분모로 쓰는 원단위를 빼고 보냅니다(`deploy/gateway.conf`의 `X-Public-Gateway`). 팀 공유 폴더(`urban-carbon_공유_*`)는 `.gitignore`에 넣었습니다.
- 탄소공간지도: 공공데이터포털 등록본은 이용허락범위 제한 없음, 사이트 표기는 "All Rights Reserved"(팀 데이터 카드에 확인 필요로 기록). 원본은 Git에 올리지 않습니다.

## 4. 넣는 방법

```powershell
# 1) 공유 묶음의 도시 폴더에서 표만 복사 (data/raw는 Git 제외)
#    data/raw/team_urban_carbon/2026-10-01/<5자리 코드>_<도시>/<연도>/grid_500m.csv, grid_100m.csv
#    data/raw/team_urban_carbon/2026-10-01/<5자리 코드>_<도시>/developments.csv
# 2) 넣기 (바뀐 파일만, --force면 전부)
docker compose exec api python -m app.cli import-team-grid
```

## 5. 알려진 자료 문제 (팀 문서에서)

- 2024년에 공장이 많은 칸(공업·관리·농림)의 배출이 크게 줄어 있음(원자료 누락 추정). 지도 상세에 "급감(원자료 누락 의심)"으로 표시합니다.
- 2017년 이후 준공 아파트의 전기가 2023년까지 작게 잡힘.
- 부산 강서구 주거 칸은 난방 배출이 거의 없음(원인 미확인).
