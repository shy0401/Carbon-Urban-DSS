# 계획서 기반 구현 보완 결과

검증일: 2026-09-14. 제출용 계획서와 이전 Phase 1–4를 기준으로 기존 자료를 보존하면서 주요 사용 흐름을 보완했다.

## 이번에 구현한 내용

| 계획 항목 | 구현 결과 |
|---|---|
| 분석 범위 일관성 | 분석연도·선택 격자를 화면 간 공유하고 저장한다. 지도에서 선택한 격자로 시뮬레이션과 보고서를 이어간다. |
| 관측 범위·연간 합계 | 모든 격자의 월별·에너지원별 동일 관측 집합을 확인해 원단위 분모를 구성한다. 일부 월만 존재하면 관측 기간 합계와 완전한 연간 값을 구분한다. |
| 모델 검증 화면 | 관측 수·격자 수·공간 블록·관측 월의 최소 조건, 실제 비교 결과, 직전 저장 검증을 표시한다. 미학습 상태와 표본 부족 상태를 구분한다. |
| 지도·대시보드 | 선택 강조, 선택 격자 확대, 실제 값 기반 범례와 결측 구분, 8개 지표, 월별 기상 차트 및 데이터 미확보 안내를 제공한다. |
| 계획안 시뮬레이션 | 5·10·20·30·40층 예시, 개념 배치도, 부지·건축면적·세대 수용량 검증을 제공한다. 입력 변경 시 이전 결과를 무효화한다. |
| 한국어 검토 보고서 | 동일 연도·격자의 최대 3개 계획안을 비교한다. 계산 결과·출처·수집 시점·근거 해시를 저장하고 이력 조회, Markdown 다운로드, 인쇄·PDF 저장을 제공한다. |
| 로컬 소형 언어모델 | Ollama의 Qwen2.5 1.5B로 근거 문장을 선정한다. 모델 응답의 근거 ID와 원문을 검증하고 오류 시 기본 서식으로 대체한다. 실제 모델 호출을 확인했다. |
| UI 안정성 | 오래된 조회 응답 취소, 서버 오류 안내, 보고서 선택 상자·데이터 카드의 모바일 가로 넘침을 수정했다. |

로컬 AI는 검증된 문장을 선택하는 제한된 요약 기능이다. 자유 형식의 정책 제안이나 숫자 재계산은 구현하지 않았다. 개념 배치도는 실제 건물 위치나 인허가 가능 배치를 보증하지 않는다.

## 최신 검증

- 백엔드 pytest: **63개 통과**, 상위 라이브러리 사용 중단 예정 경고 2개.
- 프런트엔드 Vitest: **17개 통과**, TypeScript 검사와 Vite 운영 빌드 성공.
- 기존 Chromium E2E: **9개 통과**, 브라우저 실행 오류 0건.
- 보완 Chromium E2E: **9개 통과**, 브라우저 실행 오류 0건. 분석연도 변경, 실제 지도 렌더링·선택, 30층 계산, 동일 범위 보고서, 문서 다운로드, 인쇄 스타일, 5개 모바일 경로, 서버 503 안내를 검사했다.
- 모델·분석 화면도 390px 너비에서 문서 가로 넘침이 없음을 추가 확인했다. 넓은 데이터 표는 표 영역 안에서 스크롤한다.
- 실제 로컬 모델 응답: `LOCAL_SLM`, `qwen2.5:1.5b`, 근거 ID와 원문 일치 검증 통과.
- 실행 증거: `data/validation/backend-tests-latest.log`, `frontend-tests-latest.log`, `e2e.json`, `refined/checks.json`, `local-ai-report.json` 및 화면 캡처.

이 검증은 검사한 시나리오의 결과다. 실제 에너지 자료가 없는 조건에서 예측 정확도나 모든 입력 조합의 무오류를 증명하지 않는다. 초기 JS 약 2.52MB(압축 약 774KB)의 번들 크기 경고가 남아 있다.

## 추가로 필요한 작업과 조건

| 우선순위 | 남은 작업 | 필요한 조건 |
|---|---|---|
| 1 | 실제 월별 에너지 수집·지번 및 연면적 정합성 검증, 탄소 계산 재검증 | 유효한 공공데이터 서비스키와 개별 API 승인. 현재 에너지 관측은 0행이다. |
| 2 | 공식 건축물대장·용도지역·인구 통합 및 법정 기준 확인 | 건축물대장, VWorld, SGIS의 승인 자료 또는 원본 파일. 기존 업로드만으로 모든 분석 지표가 자동 완성되지는 않는다. |
| 3 | 기업 100m 탄소격자 전용 수집·스키마·500m 집계·독립 비교 | 선도소프트 원본, 이용 조건, 공간 기준, 산정 경계·단위. 현재 전용 탄소격자 어댑터는 미구현이다. |
| 4 | 가스 포함 운영탄소·최적화 실증 | 가스 열량 기준, GWP와 배출계수 확정 및 같은 관측 범위의 월별 자료. |
| 5 | 건축 연령·층수·인구 등을 포함한 모델 확장과 실제 성능 평가 | 충분한 공간 표본과 변수 확보. 현재 실자료 MAE·RMSE·R²는 미산출이다. |
| 6 | 태양광 설비 발전량·녹지 흡수량을 반영한 고도화 | 설비 용량·일사·수종·수령 등 검증 자료. 현재 태양광 비율은 사용자 가정이며 정밀 발전 모델이 아니다. |
| 7 | 외부 서비스 운영 준비 | 로그인·권한, 버전 DB 마이그레이션, 백업·복구 운영, 부하 검증 및 초기 번들 분할. 현재 로컬 시연용이다. |

다음 단계는 1번의 실제 에너지 확보와 재검증이다. 기존의 미등록 키를 반복 호출하거나 결측을 임의 관측으로 채우지 않았다. 원본 데이터와 운영 DB 볼륨은 보존했다.

## 실행과 확인

기본 사이트: http://localhost:5173/ · 검토 보고서: http://localhost:5173/reports

```powershell
docker compose up -d --build
docker compose --profile local-ai up -d ollama
docker compose exec -T ollama ollama pull qwen2.5:1.5b
```

모델 다운로드는 최초 한 번 약 1GB이며 이후 로컬 볼륨을 재사용한다. Ollama 컨테이너 메모리 상한은 4GB다. 모델을 실행하지 않아도 기본 서식 보고서는 사용할 수 있다. 다운로드된 모델의 로컬 호출은 오프라인 데이터 시연 모드에서도 가능하다.
