## 2. 전국 단위로 할 수 있는 분석과 없는 분석

**할 수 있음 (전국 어디나, 시·도 → 시·군·구 → 읍면동 → 500m 격자)**

- 인구·가구·인구밀도(행정 2024), 500m 격자 인구의 2015→2024 증감, 주택·종사자 총량
- 연령 구성·노후 주택·아파트 비율(1km 격자 2024)
- 공동주택 단지 분포와 사용승인연도
- 조례·시행령 건폐율·용적률 상한(시뮬레이션의 법적 검토)
- 어느 시·군·구든 지도 열기: 전국 공통 자료로 500m 격자·읍면동 기본 지도를 수 초에 만듦 (가평·완주 격자 약 3,600개 실측 약 9초)

**지금은 못 함 (상세 자료가 있는 시·군·구만)**

- 에너지 사용량·원단위·탄소: 전국 자료가 없어 건축HUB·K-apt API로 지역마다 모읍니다(시·군·구 하나에 몇 시간~며칠, 일일 한도).
- 건물 형태(건폐율·용적률 추정)·용도지역 분포: VWorld를 1km 타일마다 불러 지역마다 모읍니다.
- 에너지 모델 학습·검증: 관측 에너지가 있는 곳만.

## 4. 화면 절차 (이번 변경)

1. **전국** (`/map`, 첫 화면): 시·도를 지도에서 누르거나 왼쪽 메뉴에서 고릅니다. 시·도끼리 인구·밀도·가구·인구 증감·주택·종사자·단지 수로 비교합니다.
2. 고른 **시·도의 시·군·구**가 같은 지표로 칠해지고, 왼쪽에 순위가 나옵니다. 시·군·구를 누르면 요약(지표, 에너지 관측 유무, 지역 수준)과 **지도 열기**가 나옵니다.
3. **시·도 500m 격자**(제주 제외)와 **시·군·구·읍면동** 지도는 그대로입니다.
4. 머리의 **시·도 → 시·군·구** 선택 상자로 어느 화면에서든 전국 어디나 고를 수 있습니다. 지도가 없는 곳은 고르는 즉시 기본 지도를 만들고(머리 아래 진행 알림), 멈췄던 화면은 끝나면 다시 읽습니다. 기본 지도 지역에서는 분석 화면 위에 "에너지·탄소 값은 비어 있으며 0이 아님"을 알립니다.

API: `GET /api/map/national`(시·도 지표·경계, 시·군·구 지표 목록, 빠진 블록), `GET /api/map/national/{시·도}`(시·군·구 경계와 지표). PC 실측: 처음 만들 때 약 15~25초(경계 합치기), 이후 0.1초. 시·도별 시·군·구 경계 16~84KB.
