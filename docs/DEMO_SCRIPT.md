# 5분 시연

**0:00–0:40 문제.** 전주의 주거 재개발에서 밀도를 높일 때 에너지·탄소를 어떻게 비교할지 설명한다.500m 분석셀과 실제 개발부지는 서로 다르다고 밝힌다.

**0:40–1:30 실제 공공데이터.** 수집 데이터를 열고 MOIS 코드,Kapt,전주시 공동주택 현황,기상을 확인한다. 원본과 정제 자료·수집일·해시·OFFICIAL/FALLBACK 배지를 보여준다. 인증 오류 소스도 숨기지 않는다.

**1:30–2:10 지도.** 전주시 경계와500m격자를 보여주고 강조된 호성동 LG동아 인근 섹터를 선택한다.250,000m²와 선정 사유를 설명한다. 회색 결측을 저소비로 해석하지 않는다.

**2:10–3:10 재개발 비교.** 시뮬레이션에서 개발가능부지와 동당 건축면적을 설명하고30층·40층 버튼을 눌러 FAR/BCR·수용량 변화를 보여준다. 에너지 관측이 있으면 현재/계획/차이를 표시한다. 관측이 없으면 면적계산까지만 시연하고 에너지 미확보 메시지를 명시한다.

**3:10–4:10 최적안.** 최소세대·인구 조건을 입력해 결정론적 탐색을 실행한다. 관측이 부족하면 결과 없음과 필요한 데이터 조건을 보여준다. 검증된 결과가 있을 때만 목적함수와 대안 차이를 설명한다. 법적 적합성 판정으로 소개하지 않는다.

**4:10–5:00 신뢰와 재현.** 모델 화면의 표본·검증상태와 수집 데이터의 근거를 연결한다. 오프라인 모드를 켜고 로컬 자료가 유지됨을 보여준다. 발표 전 `python -m app.cli demo`로 준비하고, 인증키 문제와 가스계수·인구·용도지역의 남은 의존성을 사실대로 마무리한다.
