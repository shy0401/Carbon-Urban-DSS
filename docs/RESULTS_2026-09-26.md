값을 지어내지 않는다. 틀린 값은 원자료에 남기고 계산에서만 뺀다. 모든 제외는 화면에 개수로 표시한다.

| 문제 | 실제 사례 | 처리 |

## 5-1. 3D 배치·일조와 용도지역 상한 (2026-09-27 개편)

**3D 배치·일조** (시뮬레이션 화면 오른쪽)
- **대지:** '대지 옮기기' 후 지도를 클릭해 대지를 옮기고, 배치 방향을 0~89° 돌린다.
- **동 형태:** 탑상형(정사각)과 판상형(3:1) 중에서 고른다.
- **동 간격:** 높이 × 0.25·0.5·0.8·1 중에서 고른다. 기본 0.5는 건축법 시행령 제86조 채광 이격 하한을 참고한 계획 가정이다.
- **그림자:** 동지·춘분·하지의 8~17시를 고르면 NOAA 태양위치식으로 그 시각의 그림자를 그린다.
- **아래 요약표:**
  - 건폐율·용적률(조례 상한 대비)
  - 최고 높이, 배치(행×열·동 간격·대지 초과 여부)
  - 대지 안 기존 건물 수, 태양 고도·그림자 길이, 그림자가 닿는 기존 건물 수
- **확인값:** 기본 대상지(cell_968500_1762000)에 12층 4동 탑상형이면 대지 안 기존 건물 5동이다. 동지 12시 태양 고도 30°, 그림자 62m이고, 그림자가 닿는 기존 건물은 2동이다.

**용도지역·조례 상한** (`GET /api/zoning/site`, 시나리오 `zoning_check`)

- API 시작 때 준비 작업을 미리 돌린다.

## 6. 지도 정보와 활용

웹 **사용 방법 → 지도 정보와 활용**(`/guide#map-info`)에 같은 내용이 있고, 지도의 범례 **정의·산식·활용**과 격자 상세 패널에도 지표마다 뜬다. 아래 표는 화면 코드(`frontend/src/lib/mapMetrics.ts`, `mapLayers.ts`)에서 그대로 뽑았다. "2025 값 있는 격자"는 2026-09-26 PC의 `/api/map?year=2025` 기준이다(916개 중, "전체"는 0을 포함해 모든 격자에 값이 있는 지표).

읽는 법:

- **빗금 격자 = 자료 없음(0이 아님).** 지표를 고르는 목록에도 지표마다 값 있는 격자 수가 나온다.
- **에너지 관측·원단위·탄소**는 공동주택(K-apt와 매칭된 지번)만의 값이다. 격자의 모든 건물 합이 아니다.
- **건물 전체 에너지**는 건축HUB가 계량한 모든 지번(상가·업무·학교·공동주택)의 합이다. 단독주택, 200세대 미만 공동주택(2020년~), 산업·수송용은 제공기관이 빼고 준다.
- **도시 형태**는 VWorld 건물 윤곽으로 낸 근사값, **건축물대장**은 공식 연면적 기반 값이다. 둘 다 격자 면적(250,000m²) 기준이며 필지 기준 법정 건폐율·용적률이 아니다.
- **인구·주택(SGIS)** 은 1km 공식 격자의 값을 그 안의 500m 격자 4개에 같이 표시한다.

활용 예:

- **감축 우선 격자 찾기**: "건물 전체 전력 탄소"로 배출 규모가 큰 격자를 고르고 → "건물 전체 전력 원단위"로 면적 대비 효율을 본다. 규모도 크고 원단위도 높으면 우선 대상이다.
- **노후 공동주택 리모델링 후보**: "2000년 이전 준공 연면적 비율"(건축물대장)과 "가스 원단위"가 함께 높은 격자.
- **개발 여력과 탄소 영향**: "용적률 (건축물대장)"과 "주거지역 비율"로 여력을 보고, 격자를 눌러 **지역 시뮬레이션**에서 층수·세대수를 바꿔 전후 탄소를 계산한다.
- **취약계층 난방**: "65세 이상 비율"·"1인가구 비율"(SGIS)과 "가스 원단위"를 겹쳐 본다.
- **자료 신뢰도**: 값이 튀면 "에너지 관측 완전성"과 격자 상세의 관측 지번 수·제외 지번 수를 먼저 확인한다.

## 7. 다시 확인하는 방법

```powershell
scripts\dss.cmd Status                          # 서비스·수집 상태
scripts\dss.cmd Backup; scripts\dss.cmd VerifyRestore -SkipE2E   # 백업과 복원 검증(pytest 포함)
```

- 수집 진행: 웹 **수집 데이터** 화면 맨 위 "빠진 자료 전부 수집" 표 (연도×자료 상태).
- 모델 검증: 웹 **모델** 화면 → "현재 자료로 검증".
- 이 문서의 표는 2026-09-26 기준이다. K-apt 과거 자료가 들어오면 지역 시뮬레이션의 2015~2023년 값이 채워진다.
