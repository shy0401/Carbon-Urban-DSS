# 알려진 한계

- 초기 `.env` 키는 공공데이터포털에서 미등록(30)으로 거부되었다. 유효한 키와 해당 서비스의 개별 활용 승인이 필요하다. 아직 관측이 없으면 에너지 차트·탄소·최적화에 완료값이 나오지 않는 것이 정상이다.
- OSM 건물과 경계는 비공식 공간 대체 자료다. 전체 도시의 모든 건물을 포함하지 않고 아파트 중심이며 일부 층수는 없다.
- 현재500m격자는 임시 정렬격자다. 공식 NGII 격자는 별도 원본과 대응표가 필요하다.
- Kapt 단지 좌표는 점이다. 단지 소비를 대표 좌표의 셀에 배정해도 지적 면적 배분의 정확성이 보장되지 않는다. 다중지번·중복 지번은 매칭을 보류한다.
- Kapt 상세는 조회 시점 정보이며2025년 당시 불변 상태를 보장하지 않는다. 단지 목록의202512 검색조건과 상세 정보의 수집 시점을 분리해 해석해야 한다.
- 전주시 공동주택 문서와 Kapt 단지는 목록 범위·기준이 다르므로 단순 행수 비교로 누락률을 단정할 수 없다.
- 기상은 ERA5-Land 재분석이다. 500m 해상도의 독립 관측값이 아니다.
- 전기계수는 검증했지만 가스 CO2eq 계수의 입력 열량 기준은 확정하지 않았다. 전체 탄소를 부분 탄소로 채우지 않는다.
- 법정 용도지역·FAR/BCR상한·인구격자가 미확보면 법적 상한과 인구 정규화 지표는 null이다.
- 통계적으로 충분한 학습자료가 없으면 검증된 ML이 아니다. 현재 원단위 모델은 행태·노후도·혼합용도·미래기후의 효과를 식별하지 않는다.
- 외부 배포용 인증·운영 마이그레이션·장애관제는 별도 단계다. 현재는 localhost용 프로토타입이다.
