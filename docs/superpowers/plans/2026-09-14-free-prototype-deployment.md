# 무료 PC 시연 배포 계획

사용자가 PC를 켜 두는 무료 시연 배포를 선택했다. 기존 Docker/PostGIS/Redis/worker/Ollama를 유지하고 Cloudflare Quick Tunnel로 HTTPS 접속을 제공한다. 공개 경로는 비밀번호 인증 gateway로 한정한다. 서버 계정·결제·도메인 구매는 필요 없다.

- [ ] 인증 없는 요청 거부, 인증 요청 통과, 외부 출처 쓰기 요청 차단을 검사하는 gateway 테스트 작성·실패 확인.
- [ ] Nginx gateway, 선택형 public-demo Compose, 비밀정보 생성·시작·중지·주소 확인 스크립트 구현.
- [ ] 운영 DB·원본 보존, 온라인 전환 및 실제 작업 큐 검증. 미등록 에너지키 제한은 그대로 표시.
- [ ] 로컬 검증 후 GitHub에 변경 반영하고 터널 공개.
- [ ] 공개 HTTPS에서 인증, 지도, 계산, 보고서 저장·다운로드, 로컬 AI, DB 및 worker 검증.

공개 주소와 비밀번호는 GitHub에 저장하지 않는다. PC 절전·종료 시 서비스 중단, 터널 재생성 시 주소 변경, 무료 터널의 가용성 제한을 인계 문서에 명시한다.
