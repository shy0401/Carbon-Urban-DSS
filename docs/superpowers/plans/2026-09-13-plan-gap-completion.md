# 계획서 미구현 기능 보완

사용자가 제출용 계획서와 이전 Phase 1–4에 따른 순차 구현을 요청했다. 기존 실행 프로젝트를 보존하고 이 계획을 순서대로 수행한다.

## 설계
분석 범위는 연도와 격자를 하나의 상태로 관리한다. 원단위 분모는 모든 격자에서 검증된 동일 지번 집합을 사용하며 부분 연간 합계는 완전한 연간 값과 구분한다. 보고서는 DB 관측·저장 시나리오·출처의 스냅샷이며 로컬 모델은 검증된 근거 문장만 선정할 수 있다. 숫자 계산이나 법적 권고를 언어모델에 맡기지 않는다. UI는 현재 청록색 계열을 유지하면서 가독성, 결측, 범례, 모바일 배치, 인쇄를 보완한다.

## 외부 의존성
미등록 에너지키를 재시도하거나 가짜 관측을 만들지 않는다. 공식 인구·용도지역·기업 탄소격자·가스계수는 원본 승인/검증 이후 분석 가능하다. 태양광 설비와 녹지 흡수의 실증자료 없이 정확한 상쇄값을 제시하지 않는다. 대규모 기능 추가보다 계획서의 주요 사용 흐름 완결을 우선한다.
