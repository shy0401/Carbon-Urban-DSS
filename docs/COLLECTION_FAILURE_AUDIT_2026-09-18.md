# 수집 실패 원인 조사 및 조치 보고서

- 최초 확인일: 2026-09-18
- 최종 재검증일: 2026-09-22

## 2026-09-23 추가 확인

- `.env`의 `DATA_GO_KR_SERVICE_KEY` 값은 발급 키가 아니라 **한글 예시 문구(14자)**였다. 이 값을 그대로 보내면 공급기관은 `SERVICE_KEY_IS_NOT_REGISTERED`(30)를 반환한다. 이제 한글·공백·따옴표·예시 문구 값은 수집 전 `환경변수 형식 오류`로 차단하고 화면에는 `형식 오류`로 표시한다(값은 출력하지 않음).
- VWorld 키는 형식이 정상이었지만 도메인 후보 7가지 모두 `INCORRECT_KEY`였다. 인증키 관리 화면의 활용API에 **2D데이터 API가 체크되지 않은 것**이 원인이며 사용자가 체크했다. VWorld 거절 기록은 키와 도메인에 묶어, 도메인을 고치면 바로 재시도한다. 등록 정보를 고친 뒤에는 `scripts\dss.cmd Collect -RetryRejected`로 캐시된 거절만 지우고 재시도한다.
- SGIS는 새 키로 2024년 행정통계·행정동 경계 수집에 성공했다.

## 조사 결과

| 수집원 | 실제 확인 결과 | 원인 | 현재 처리 |
|---|---|---|---|
| K-apt 월별 에너지 | HTTP 403, `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`, 코드 30 | 현재 `DATA_GO_KR_SERVICE_KEY`가 공급자에게 등록된 키가 아님 | 동일 키의 반복 호출을 1시간 차단. 키 교체 시 즉시 재검증 가능 |
| KMA ASOS | HTTP 403, 같은 오류와 코드 30 | 현재 키 미등록 또는 해당 서비스 활용신청 미승인 | 동일 |
| 건축HUB 건물에너지 | HTTP 403, 코드 30 | 현재 키 미등록 또는 해당 서비스 활용신청 미승인 | 동일 |
| SGIS 인구·가구 | 호출 전 차단 | `SGIS_CONSUMER_KEY`, `SGIS_CONSUMER_SECRET` 미설정 | 외부 요청과 실패 작업을 만들지 않고 필요한 변수 표시 |
| VWorld 용도지역·연속지적 | 호출 전 차단 | `VWORLD_API_KEY`, `VWORLD_DOMAIN` 미설정 | 외부 요청과 실패 작업을 만들지 않고 필요한 변수 표시 |
| ERA5-Land 대체 기상 | 정상 수집 | 인증키가 필요 없는 공개 API | 자동 수집 기본 선택으로 유지 |

공공데이터포털 세 API는 운영 코드와 같은 URL·파라미터로 캐시를 우회해 직접 확인했다. 비밀값은 로그·DB·응답에 출력하지 않았다. 수집기의 응답 파싱이나 PostGIS 적재 전에 공급기관 인증 단계에서 거절되므로, 코드를 변경해 관측값을 만들 수 있는 오류가 아니다.

## 직접 수정한 내용

1. 수집 요청 전에 환경변수 누락과 최근 인증 거절을 검사한다. 차단된 요청은 `409`로 반환하며 `CollectionJob`을 만들지 않는다.
2. HTTP 200 오류 응답을 포함한 인증 오류 캐시는 키의 SHA-256 지문에만 연결한다. 같은 키는 한 시간 동안 반복 호출하지 않고, 키가 바뀌면 즉시 새 요청을 허용한다. SGIS는 consumer key와 secret 조합의 지문을 사용한다.
3. 수집 화면에서 실행 불가능한 데이터셋을 비활성화하고 차단 사유를 항목 안에 표시한다. 현재 실행 가능한 ERA5-Land가 자동 선택된다.
4. 작업 이력의 `errors[]`를 화면에 표시해 데이터셋 이름과 실제 실패 원인을 확인할 수 있게 했다.
5. API, CLI, Celery 작업 큐가 같은 사전 검사 규칙을 사용한다.

## 외부 계정에서 해야 하는 조치

아래 값은 서비스 소유자의 계정에서만 발급·승인할 수 있어 프로젝트 코드가 대신 생성할 수 없다.

1. 공공데이터포털에서 [K-apt 에너지](https://www.data.go.kr/data/15012964/openapi.do), [ASOS 일자료](https://www.data.go.kr/data/15059093/openapi.do), [건축HUB 건물에너지](https://www.data.go.kr/data/15135963/openapi.do)를 각각 활용신청한다.
2. 승인된 일반 인증키의 Decoding 값을 `.env`의 `DATA_GO_KR_SERVICE_KEY`에 넣는다.
3. SGIS 개발자 키·비밀값과 VWorld 키·등록 도메인을 `.env`에 넣는다.
4. 다음 명령으로 새 환경을 적용한다.

```powershell
docker compose -f compose.yaml -f compose.demo.yaml up -d --force-recreate api worker
```

5. 수집 화면에서 `SMOKE`를 먼저 실행한다. K-apt는 1단지×1개월, KMA는 전주 146 관측소 1개월, VWorld는 한 격자 bbox가 성공한 뒤 범위를 확대한다.

키 값은 GitHub, 보고서, 화면 또는 채팅에 넣지 않는다. 세부 신청·다운로드 절차와 필드 목록은 [데이터 재설정·수집 안내](DATA_SETUP_GUIDE.md)를 따른다.
