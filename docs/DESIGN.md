# Carbon Urban DSS 디자인 시스템 — D안 「도시계획 도면」

이 문서는 `frontend/`의 시각 표현 기준이다. 저장 위치는 `docs/DESIGN.md`를 권장한다.

우선순위: **데이터 원칙(README·CARBON_METHOD·SRS) > 이 문서 > 개별 컴포넌트의 기존 스타일.**
이 문서가 데이터 의미와 충돌하면 데이터 의미를 따르고, 이 문서를 고친다.

---

## 1. 원칙

1. **도면처럼 읽힌다.** 도시계획 도면의 관례(용도지역 색, 표제란, 범례, 축척 표기)를 UI 문법으로 쓴다. 도시계획 담당자가 설명 없이 읽을 수 있어야 한다.
2. **근거의 종류가 먼저 보인다.** 이 프로젝트는 실측, 공공데이터 계산, 추정, 시나리오를 분리한다. 모든 수치는 어떤 근거인지 색 하나가 아니라 **라벨 + 선/패턴**으로 구분한다. 이 문서에서 가장 중요한 규칙이며, 디자인에서 과감함을 쓰는 유일한 곳이다.
3. **없는 값은 0이 아니다.** 결측·미확보는 램프의 가장 옅은 색도, 0도, 빈칸도 아니다. 전용 해치 패턴과 "자료 미확보" 문구로 표시한다.
4. **크롬은 조용하게, 색은 데이터에만.** 사이드바·버튼·패널은 무채색과 먹색 녹색으로 누르고, 채도는 지도·차트·용도지역에만 쓴다.

규칙:
- 상태는 **서버 응답의 필드를 그대로 매핑**한다. 프런트에서 상태를 새로 추론하지 않는다. 필드가 없으면 표시하지 말고 백로그에 남긴다.
- 한 수치에 상태가 둘 이상이면(예: 일부 월만 관측) "관측 기간 합계"와 "완전 연간 값"을 분리해 각각 배지를 단다.
- 추정·시나리오 값은 요약 카드에서도 배지를 생략하지 않는다.

### 2.4 지표 램프

용도지역 색과 겹치지 않도록 흙색 계열(부하)과 녹색 계열(편익)을 쓴다. 5단계, 구간 경계는 실제 값으로 계산한다(기존 "실제 값 기반 범례" 유지).

```css
:root {
  /* 부하: 에너지 사용량, 운영탄소 등 높을수록 나쁨 */
  --load-1: #F1EAD9; --load-2: #E2C58F; --load-3: #CC9350; --load-4: #A65B2B; --load-5: #6A2E17;
  /* 편익: 태양광 비율, 감축량, 흡수량 등 높을수록 좋음 */
  --gain-1: #E6EFE2; --gain-2: #BCD6B1; --gain-3: #88B783; --gain-4: #568F60; --gain-5: #2C6343;
  /* 증감: 계획안 대비 현황, 음수=감소 */
  --diff-neg-2: #2C6343; --diff-neg-1: #9CC495; --diff-zero: #F3F1EA; --diff-pos-1: #D9A56A; --diff-pos-2: #8A3F1E;
}
```

- 녹색을 배출·사용량 증가에 쓰지 않는다.
- 결측 격자는 `--load-1`이 아니라 해치로 칠한다. 범례에도 "자료 미확보" 칩을 램프와 **떨어뜨려** 따로 둔다.
- 무지개(jet) 램프 금지.

## 3. 타이포그래피

- 서체: **Pretendard Variable 한 가지.** 오프라인 시연 모드가 있으므로 CDN이 아니라 로컬에 번들한다(`pretendard` npm 패키지의 dynamic subset CSS 또는 `frontend/public/fonts`의 woff2). 대체 스택: `"Pretendard Variable", Pretendard, -apple-system, "Apple SD Gothic Neo", "Malgun Gothic", sans-serif`.
- 모든 수치: `font-variant-numeric: tabular-nums;`
- 한국어 줄바꿈: `word-break: keep-all; overflow-wrap: anywhere;`

| 용도 | 크기 / 굵기 / 행간 |
|---|---|
| 범례, 캡션, 표제란 라벨 | 12px / 400 / 1.4 |
| 표, 입력 라벨, 배지 | 13px / 500 / 1.45 |
| 본문 UI | 14px / 400 / 1.6 |
| 패널 제목 | 16px / 600 / 1.4 |
| 화면 제목 | 20px / 600 / 1.35 |
| 핵심 수치 | 28px / 600 / 1.2 |

- 굵기는 400, 500, 600만 쓴다.
- 단위는 수치 뒤 한 칸 띄우고 0.85em, `--ink-3`: `12,480 tCO₂eq`. 단위를 생략하지 않는다.
- 천 단위 쉼표. 소수: 탄소·에너지 정수, 비율 소수 1자리, R² 소수 2자리.
- 제목 위에 영문 대문자 눈썹 라벨을 달지 않는다. 한 단어만 색·굵기로 강조하지 않는다.

### 4.2 표제란 (Title block)

도시계획 도면의 표제란을 옮긴 이 프로젝트 고유의 요소. 분석 범위(`useAnalysisScope`의 연도·선택 격자)를 항상 보이게 한다.

```
┌──────────┬──────────┬──────────────┬──────────────┬──────────┐
│ 분석연도  │ 격자      │ 선택          │ 자료 기준일    │ 모드      │
│ 2025     │ 500m 주거 │ 격자 3개      │ 2026-09-18   │ 오프라인  │
└──────────┴──────────┴──────────────┴──────────────┴──────────┘
```
- 1px `--line-strong` 테두리, 칸 사이 세로선, 반경 2px, 라벨 12px `--ink-3`, 값 13px 500.
- 표시 전용. 범위 변경 로직은 기존 컨트롤을 그대로 쓴다.
- 검토 보고서의 머리글에도 같은 표제란을 쓰고 근거 해시 칸을 추가한다.
- 모바일에서는 한 줄 요약(연도, 선택 격자 수)으로 접고 눌러서 펼친다.

### 4.4 모바일 (≤ 390px 기준 검증)

- 문서 가로 넘침 0을 유지한다(기존 E2E 검증 조건).
- 사이드바는 상단 햄버거 드로어 또는 하단 탭(현재 구조 중 가벼운 쪽).
- 지도 전체 폭, 상세 패널은 지도 아래로 쌓는다.
- 넓은 표는 표 컨테이너 안에서만 가로 스크롤.

### 4.5 간격·모서리·높이

- 간격 4px 단위: 4, 8, 12, 16, 24, 32.
- 모서리는 위계를 드러낸다: 지도·범례 칩·표제란·배지 **2px**, 버튼·입력 **6px**, 패널 **8px**. 모든 요소에 같은 반경을 쓰지 않는다.
- 그림자 대신 1px 선으로 층을 나눈다. 드롭다운·팝오버만 `0 4px 16px rgba(28,38,34,.12)`.

## 5. 컴포넌트 규칙

### 근거 배지 `ProvenanceBadge`
- 높이 20px, 좌우 6px, 12px 500, 반경 2px, 2.3의 색 쌍.
- 추정은 1px 점선 테두리, 시나리오는 1px 점 테두리, 나머지는 테두리 없음.
- 색만으로 구분하지 않도록 항상 한글 라벨을 쓴다.

### 결측 값 `MissingValue`
- 값 자리에 "—", 아래 12px `--ink-3`로 사유 한 줄. 예: "월별 에너지 관측 없음".
- 카드 전체가 결측이면 카드 배경에 `.is-missing` 해치.

### 지표 카드 (8개)
- 라벨 13px `--ink-2` → 값 28px 600 + 단위 → 근거 배지 + 기준(연도 또는 관측 기간) 12px.
- 흰 바탕, 1px `--line`, 반경 8px, 그림자 없음. 모든 카드를 같은 모양으로 반복하되 지도 옆 패널에서는 2열 밀집형.

### 범례
- 순차 5칸 + 각 경계의 실제 값, 단위, 지표명.
- "자료 미확보" 해치 칩은 8px 간격을 두고 분리.
- 용도지역 오버레이가 켜져 있으면 용도지역 범례를 별도 블록으로 추가.

### 표
- 머리 `--surface-sunk`, 13px 500. 행 구분 1px `--line`, 줄무늬 없음.
- 수치 오른쪽 정렬, 단위는 머리에만.
- 결측 셀은 "—" + `title="자료 미확보"`, 추정 셀은 값 옆 작은 "추정" 배지.

### 차트
- 격자선 `--line`, 축 글자 12px `--ink-3`, 주 계열 `--primary` 1.5px.
- 결측 월은 선을 끊고(0으로 잇지 않음) 해당 구간에 옅은 해치 띠 + "자료 없음".
- 추정 계열 점선, 시나리오 계열 짧은 점선. 툴팁에 근거 라벨 포함.

### 빈 상태 · 모델 상태
- 미학습, 표본 부족, 데이터 미확보는 서로 다른 문구로 구분한다(기존 구분 유지).
- 형식: 무엇이 없는지 한 문장 → 필요한 조건 목록(현재값/기준값) → 할 수 있는 행동 버튼.
- 예: "월별 에너지 관측이 없어 운영탄소를 계산하지 않았습니다." → 조건: 관측 행 0 / 필요 1 이상 → [수집 상태 보기]
- 사과하지 않는다. 모호하게 쓰지 않는다.

### 오류 안내
- `--danger-bg` 배너, 무엇이 실패했는지 + 다음 행동. 원시 예외 문자열 노출 금지.

### 버튼
- 화면당 주 버튼(`--primary` 채움) 1개. 나머지는 흰 바탕 1px `--line-strong`.
- 동사로 끝나는 짧은 이름: "보고서 저장", "계획안 비교", "다시 수집". 버튼 이름과 완료 메시지를 일치시킨다("보고서 저장" → "보고서를 저장했습니다").

## 6. 지도 규칙

- 격자 면: 지표 램프, 불투명도 0.85. 격자 경계: 배경지도 위 흰색 0.6 / 오프라인 바탕 위 `--line-strong`.
- 선택 격자: 2.5px `--select-line` + 바깥 1px `--select-halo`. 호버: 1.5px `--select-line` 60%.
- 결측 격자: 해치 패턴. 라이브러리에 맞게 구현한다.
  - MapLibre/Mapbox: `map.addImage('hatch-missing', …)` 후 `fill-pattern`.
  - Leaflet(SVG): 오버레이 pane의 `<defs><pattern>` 참조.
  - Canvas 렌더러: `ctx.createPattern`.
- 배경지도: 채도를 낮춘 밝은 타일. 타일 장애·오프라인이면 분석 도형은 유지하고(기존 동작), 지도 바탕을 `--canvas` + 1km 간격 1px `--line` 참조 격자로 칠해 도형이 허공에 뜨지 않게 한다. 표제란 모드 칸에 "배경지도 없음" 표시.
- 축척 막대와 북쪽 표시를 좌하단에 작게 둔다.

## 7. 인쇄 (검토 보고서)

- A4 세로, 여백 18mm, 흰 바탕, 사이드바·버튼 숨김.
- 첫 장 머리에 표제란 + 근거 해시 + 생성 시각.
- 해치·점선은 인쇄에서도 유지(`print-color-adjust: exact`).
- 표와 차트는 페이지 사이에서 잘리지 않게 `break-inside: avoid`.
- 계획안 비교는 2.6 색 + 계획안 이름을 함께 인쇄.

---

## 8. 접근성

- 본문 대비 4.5:1 이상, 큰 수치 3:1 이상.
- 포커스 링: `outline: 2px solid var(--focus); outline-offset: 2px;` 모든 인터랙티브 요소.
- 색만으로 의미를 전달하지 않는다(근거 라벨, 해치, 선 모양).
- 지도에서 선택한 격자는 상세 패널 제목에도 격자 ID를 텍스트로 표시.
- `prefers-reduced-motion`이면 선택 확대 애니메이션을 끈다. 그 외 애니메이션은 선택 확대(300ms ease-out) 하나만 쓴다.

---

## 9. 하지 않는 것

- 그라데이션, 글로우, 카드 그림자, 유리 효과.
- 결측을 0, 빈칸, 램프 최저색으로 표시.
- 배출·사용량 증가를 녹색으로 표시.
- 외부 폰트·아이콘 CDN(오프라인 모드에서 깨진다).
- UI 킷 전체 도입(TailAdmin 등은 레이아웃 패턴만 참고). 초기 JS 번들을 늘리지 않는다.
- 이모지 아이콘, 영문 대문자 눈썹 라벨, "A · B · C"식 메타 문자열.
- 컴포넌트 안 hex 하드코딩(`tokens.css`, `palette.ts`만 예외).

## 10. 구현 메모

- `tokens.css`는 앱 진입점에서 한 번 import. Tailwind를 쓰고 있다면 theme 색을 CSS 변수 참조로 확장한다.
- `palette.ts`는 지도·차트용 동일 값. 두 파일의 키가 어긋나지 않도록 Vitest로 키 일치 테스트를 추가한다.
- 하드코딩 점검: `rg -n "#[0-9a-fA-F]{3,8}\b" frontend/src --glob '!**/tokens.css' --glob '!**/palette.ts'`
- 다크 모드는 이번 범위가 아니다. 토큰 구조만 대비해 둔다.
