# 실제 접근 결과

소스별 행수는 [DATA_SOURCES](DATA_SOURCES.md), 상세 근거는 [SOURCE_RESEARCH](SOURCE_RESEARCH.md)를 참조한다.

건물에너지 포털 설명과 공개 Swagger를 내려받아 지번별 월간 전기·가스 경로와 `useQty`의 kWh 단위를 확인했다. 요청 필드는 `sigunguCd`, `bjdongCd`, `bun`, `ji`, `useYm`, 페이지, 서비스키다. K-apt에서 단일 지번을 확인한 후보를 우선하고 최소 1행 탐색 후 제한된 페이지를 수집한다. 제공 키는 HTTP 403 / `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` / 결과 30으로 거부되었다. 키 원문은 기록하지 않는다.

대안으로 K-apt 공개 페이지를 조사하여 단지 목록·좌표·연면적을 확보했으나 익명 에너지 페이지에서 월별 사용량은 얻지 못했다. 관리비 금액은 사용량으로 대체하지 않았다. 건축물대장 및 KMA ASOS는 개별 승인 어댑터로 분리했다.

OSM 실제 경계·아파트 도형과 ERA5-Land 기상을 보존하되 공식 관측으로 승격하지 않는다. 법정 용도지역·인구·NGII 격자는 미확보다. 수동 보강은 업로드 미리보기 → 필드 매핑 → 출처·기간·좌표계 등록으로 진행하며 미검증 업로드가 검증 자료를 조용히 교체하지 않는다. 공식 격자 ID가 다르면 공간 대응표를 기록한다.
