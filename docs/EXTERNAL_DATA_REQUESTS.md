## 1. 공공데이터포털 운영계정 신청 — 활용 사례 문구

신청 대상: K-apt 공동주택 에너지 API(공공데이터포털 15012964). 같은 방식으로 건축HUB 건물에너지 API(15135963)도 신청할 수 있습니다.

```
활용 목적: 대학 캡스톤 프로젝트 「Carbon Urban DSS」(관측 건물 에너지 기반 도시 탄소 의사결정 지원 도구) 개발·검증
활용 내용: 공동주택 단지별 월별 전력·가스·수도 사용량을 500m 국가기본격자에 배치해 운영 탄소(전력 × 온실가스종합정보센터 승인 계수)를 계산하고,
          개발 전후 비교와 목표 감축률 역산(효율·재생에너지·태양광 용량)에 씀. 2015~2025년, 전주·서울 강동·부산 강서·세종 등 4~6개 시·군·구.
필요 호출량: 단지 × 월 1건. 예) 세종 224개 단지 × 12개월 × 10년 ≈ 26,900건. 전주(2015~2019)·서울 강동·부산 강서·세종(2015~2024) 합계 약 7.3만 건(단지 수 전주 364·강동 152·강서 52·세종 224) → 개발계정 1일 5,000건으로 보름 가까이
결과물: GitHub 저장소 https://github.com/shy0401/Carbon-Urban-DSS (원자료는 올리지 않음), 사용자 매뉴얼·분석 보고서
```

## 2. SGIS 500m 격자 통계 재신청

처음 신청과 같은 조건(500m, 총괄 항목)으로 **빠진 주제·블록만** 신청합니다.

```
자료: 격자 통계 500m (총괄 항목)
주제·블록·연도: 주택 — 다마 블록 2015~2022년 / 사업체 — 다마 블록 2015~2024년 / 종사자 — 다마 블록 2015~2024년
사용 목적: 대학 캡스톤 연구(격자 단위 건물 에너지·탄소 분석의 인구·주택 맥락 지표), 원자료 재배포 없음
```

## 3. 한국부동산원(건축HUB) 문의 — 가스 사용량 환산 기준

```
제목: 건축HUB 건물에너지 OpenAPI 가스 사용량(kWh) 환산 기준 문의

건축HUB 건물에너지 OpenAPI(공공데이터포털 15135963)의 가스 사용량은 kWh 단위로 제공됩니다.
도시가스 사용량(㎥ 또는 MJ)을 kWh로 바꿀 때 총발열량 기준인지 순발열량 기준인지, 적용한 열량값(MJ/㎥)과 기준 연도를 알려 주실 수 있을까요?
온실가스 산정(순발열량 × 배출계수)에 쓰려고 합니다. 'OpenAPI활용가이드_건축HUB_건물에너지_1.0.hwp'에서 찾지 못했습니다.
```

## 4. 선도소프트 100m 탄소격자 요청

```
제목: 100m 탄소격자 원본 자료 요청 (캡스톤 비교 검증용)

이 도구의 500m 격자 운영 탄소(건축HUB·K-apt 관측 에너지 × 승인 계수)와 귀사 100m 탄소격자를 같은 칸에서 비교하려 합니다.
가능한 범위에서 다음을 부탁드립니다.
- 원본 파일(전주시, 가능하면 서울 강동·부산 강서·세종) 과 연도
- 좌표계(CRS)와 격자 ID 규칙, 단위(tCO2e 또는 kgCO2eq), 포함 부문(전기·가스·지역난방·수송 등)
- 산정식과 사용한 계수, 이용 조건(외부 공개·재배포 가능 여부)
```
