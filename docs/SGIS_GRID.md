# SGIS 격자 통계 1km (2024) 적용

2026-09-25 추가.

## 원본

공공데이터포털 [국가데이터처_SGIS 격자 통계 및 경계](https://www.data.go.kr/data/15141768/fileData.do)의 2025-06-30 공개본을 씁니다. 기준시점은 2024년 6월 30일입니다.

패키지 구성:

- `1. 통계`: `<연도>년_<부문>_<100km 블록>_1K.csv`. 열은 기준연도, 격자코드, 통계항목, 통계값이고 CP949입니다.
- `2. 경계`: `grid_<블록>_1K.shp`. EPSG:5179 1km 정사각형이고 필드는 `GRID_CD`입니다.
- `3. 코드집`: 통계항목 코드와 이름.
- `4. (참고1)`: SGIS 소지역 통계 이용매뉴얼.

이 패키지는 **1km 격자만** 제공합니다. 500m·100m 격자 통계는 SGIS 자료신청이 필요합니다. 500m는 총괄 항목만 제공됩니다.

## 격자코드

코드 모양은 `<x블록><y블록><XX><YY>`입니다(예: `다마6862`). 블록 글자 순서는 가나다라마바사아입니다.

- x = 700000 + 100000 × (x블록 순서) + 1000 × XX
- y = 1300000 + 100000 × (y블록 순서) + 1000 × YY

위 식은 격자의 왼쪽 아래 모서리(EPSG:5179)입니다. 전주는 `다마` 블록 안에 있습니다.

프로젝트 500m 격자(`cell_<x>_<y>`, 왼쪽 아래 모서리)는 1km 격자 안에 정확히 4개씩 들어갑니다. 그래서 500m 격자의 소속 1km 격자는 좌표만으로 정해집니다.

## 자르기와 가져오기

1. `scripts/sgis/extract_sgis_grid.py`가 전주 범위(EPSG:5179 954000~977000, 1748000~1768000)만 잘라 `data/raw/sgis_grid_1k/<기준연도>/`에 둡니다.
   - 만드는 파일: `cells.csv`, `stats.csv`, `items.json`, `manifest.json`
   - 모든 경계 도형이 코드에서 계산한 정사각형과 같은지 확인하고, 다르면 중단합니다.
   - 표준 라이브러리만 씁니다. 코드집 이름은 openpyxl이 있을 때만 읽습니다.
   - 2024년 결과: 1km 격자 460개, 통계값 49,270행, 이름이 붙은 항목 326개.
2. API가 시작할 때 `import_sgis_grid`가 번들을 `sgis_grid_cells`·`sgis_grid_stats` 테이블에 넣습니다. 같은 행 수로 이미 들어 있으면 건너뜁니다.
3. 수동으로 다시 넣으려면 아래 명령을 씁니다.

```powershell
docker compose run --rm --no-deps -v "${PWD}:/work" -w /work api python scripts/sgis/extract_sgis_grid.py --source "국가데이터처_SGIS 격자 통계 및 경계_20250630/국가데이터처_SGIS 격자 통계 및 경계"
docker compose exec api python -m app.cli import-sgis-grid --force
```

원본 패키지 폴더는 `.gitignore`(`국가데이터처_SGIS*/`)로 빠지고, 잘라 둔 번들은 `data/raw/`라 git에는 들어가지 않습니다. 팀 번들(`scripts\dss.cmd ExportBundle`)에는 DB와 `data/raw`가 같이 들어갑니다.

## 표시 규칙

- **잡음**
  - 인구·가구·주택: 5 미만 값은 0 또는 5로 확률 대체되고, 그 이상은 최대 ±7의 잡음이 있습니다.
  - 사업체·종사자: 3 미만 값은 0 또는 3으로 대체되고, 그 이상은 ±4입니다.
  - 화면과 보고서에 이 사실을 적습니다. 0이나 5인 총계는 "5 미만일 수 있는 대체값"으로 표시합니다.
- **행이 없는 격자·항목**은 통계 없음입니다. 0으로 채우지 않습니다. 지도에서는 결측(해치)입니다.
- 세부 항목의 합은 총계와 같지 않습니다. 총계는 `to_*` 항목을 씁니다. 구성비는 그 분포의 항목 합 기준입니다.
- 비율은 기준(연령별 인구 합·총가구·주택 합)이 20 미만이면 계산하지 않습니다.
- **500m 격자**에는 소속 1km 격자의 값·밀도·비율을 붙입니다. 개수를 4로 나누지 않습니다. 1km 격자가 1km²라서 총계가 곧 밀도(/km²)입니다.
- **지역 시뮬레이션**
  - 관측: 구역이 걸친 1km 격자 전체의 합입니다. 구역보다 넓은 범위이며, 구역이 그 격자 면적의 몇 %인지 함께 적습니다.
  - 추정: 면적 비례 인구·가구입니다(1km 값 × 구역 안 500m 격자 수 ÷ 4). `ESTIMATED`로 따로 표시합니다.
- 행정동 SGIS 통계(API)는 그대로 행정동 값으로 두고, 격자 값과 섞지 않습니다.

## API와 화면

- `GET /api/sgis-grid/meta`: 기준연도, 격자 수, 행 수, 번들 목록, 규칙.
- `GET /api/map`
  - 격자마다 `sgis1k_code/year/status`, `sgis1k_population/households/housing/businesses/workers`를 붙입니다.
  - 밀도·비율로 `sgis_pop_density`, `sgis_housing_density`, `sgis_worker_density`, `sgis_elderly_pct`, `sgis_single_household_pct`, `sgis_old_housing_pct`, `sgis_apartment_pct`를 붙입니다.
  - 전체 설명은 `sgis_grid`에 있습니다.
- 대시보드 `context.sgis_grid`: 선택 격자의 소속 1km 격자 요약(분포 포함).
- `POST /api/areas/analyze`의 `history.sgis_grid`: `overlap`(관측 합계), `estimated`(추정), `coverage_pct`.
- 근거 문장
  - 격자 보고서: `context_sgis_grid`
  - 지역 보고서: `sgis_grid`, `sgis_grid_shares`
  - 지역 보고서 마크다운에는 "지역 특성" 표가 들어갑니다.
- 화면
  - 지도 분석 지표 묶음 "인구·주택 (SGIS 1km)" 7개와 격자 상세
  - 대시보드 "인구·주택" 패널
  - 지역 시뮬레이션 "지역 특성"
  - 사용 방법 `#sgis`
